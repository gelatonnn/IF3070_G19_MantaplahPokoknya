# Hasil run

Hasil HC tersedia di `hc_main/` untuk dataset utama 90 kendaraan. Folder ini
memuat empat varian dengan tiga seed, JSON detail, ringkasan CSV, dan PNG state
awal/akhir serta riwayat pencarian. Baca `../docs/HILL_CLIMBING.md`
untuk parameter dan definisi metrik. Hasil SA/GA belum tersedia.

Untuk setiap run, catat dataset dan hash-nya, seed, parameter, initial/final
state (termasuk kendaraan di luar kapal), total fee/value akhir, hasil cek
constraint, durasi, serta riwayat nilai per iterasi untuk visualisasi.
Tambahkan metrik khusus algoritma sesuai spesifikasi tugas.

Gunakan nama folder per algoritma dan konfigurasi agar hasil anggota tim tidak
saling tertimpa. Data utama tim tetap `../data/data.json`.
